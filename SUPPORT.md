# Support

This starter is maintained as an open-source reference project. It does not
provide a support SLA, guaranteed response time, or production operations
service.

## Where to ask

- Use GitHub Discussions for setup questions, implementation guidance, and
  community troubleshooting.
- Use the repository bug-report form for reproducible starter defects. Include
  only sanitized versions, steps, public error categories, and offline test
  evidence.
- Use the feature-request form for bounded proposals that remain within the
  starter's documented flight, hotel and illustrative-widget scope.

Do not place credentials, authorization headers, provider response bodies,
customer information, private deployment URLs, or other sensitive data in an
issue or discussion.

## Provider and platform boundaries

Nuitee account access, Flights entitlement, sandbox inventory, provider
availability, and production-provider enablement are owned by Nuitee and should
be raised through the support route associated with the developer's Nuitee
account.

Noodle runtime or CLI behavior should first be reproduced with the exact
package version and the smallest sanitized case. Keep application defects,
Nuitee/provider behavior, and Noodle platform behavior classified separately.

## Security reports

Do not report a suspected vulnerability publicly. Follow [SECURITY.md](SECURITY.md).
The repository must not become public until the maintainers have enabled and
documented a monitored private reporting route.
